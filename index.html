Configurar URL por proveedor
Cada proveedor ya tiene asignada una búsqueda automática para que el sistema encuentre precios solo. Si conocés la página oficial del proveedor, reemplazá la URL: se usará como fuente prioritaria para todos sus productos que no tengan su propia URL configurada.

Cómo funciona

Precio de lista: viene de tu Excel base.

Precio oficial: se busca en internet al tocar "Actualizar", usando la descripción, el proveedor y la URL configurada (del producto o, si no tiene, la del proveedor). No se ejecuta solo en segundo plano — cada vez que abrís el panel, vas a ver qué productos quedaron desactualizados (más de 1 día) para refrescarlos con un clic.

Los resultados se guardan en este panel, así que no hace falta re-buscar lo que ya está al día.
